# TUR021 — Normal şifreli kasa açılışında yazılabilir SQLite öncesi salt-okunur kimlik doğrulama

**Baz:** TUR020 stacked Draft PR #21 HEAD `fbce8366d1d2701e9ac4e483929110d2a1b06dbd`.
**Tek benzersiz kusur:** `EncryptedArticleNotes` normal public constructor, mevcut SQLite dosyasını `new ArticleNoteStore(path,readOnly:false)` ile `ReadWriteCreate` olarak açıyor, `CREATE TABLE IF NOT EXISTS ArticleNotes` ve indeks DDL'si çalıştırıyordu. Ancak `SaltKey` / `CheckKey` kasanın EAL4 kimliği ve AES-GCM parola sentinel'i **ancak bu DDL'den sonra** kontrol ediliyordu. Yanlışlıkla mevcut yabancı SQLite seçilirse başarılı olmayan bir kasa açılışı yine de yabancı dosyada `ArticleNotes` şeması oluşturabilirdi. TUR016 yalnız `PreviewRestore` için read-only kapısıydı; normal unlock koruması değildi.

**Düzeltme:** Sadece **mevcut** kasa için `EncryptedArticleNotes(fullPath,passphrase,readOnlyExisting:true)` ile salt-okunur ön kimlik doğrulama ve parola sentinel decrypt'i yapılır. Bu güvenli şekilde tamamlanmazsa yazılabilir `ArticleNoteStore` asla kurulmaz. Sonra normal constructor tekrar doğrulama ve yazma davranışını sürdürür. Yeni/eksik kasanın ilk kurulumu değişmez. Hasarlı kullanıcı notunda mevcut `CheckIntegrity=false` / `BackupTo` ret davranışı korunur. Önceden açılmış dosya ile sonra açılan dosya arasında **TOCTOU ve NTFS lock güvenliği garanti edilmez**.

**6 odaklı sentetik test:** (1) yabancı SQLite dosyası SHA/şema değişmez (2) legacy şifresiz `ArticleNotes` şifresiz notları SHA değişmez, ret (3) yanlış parola kaynak SHA korunur (4) mevcut geçerli kasada yazma (5) eksik kasanın yeni oluşturulması (6) hasarlı AES-GCM kullanıcı notunda mevcut tanıma davranışı ve yedek reddi. Mevcut 128 test korunur; CI sonucu ayrı kanıtlanacak. Manuel UAT 92+6=98, fiziksel Windows oturumu NOT_RUN.
